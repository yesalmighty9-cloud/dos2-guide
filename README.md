# คู่มือ DOS2 (dos2-guide)

คู่มือเล่น Divinity: Original Sin 2 – Definitive Edition ภาษาไทย แบบกันสปอยล์ · static HTML ล้วน เปิดผ่าน GitHub Pages

## โครงสร้าง
| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | หน้าแรก + วิธีใช้ (ต้นแบบ header/footer ของทุกหน้า) |
| `mechanics.html` | ระบบเกม & บิลด์ — **ไฟล์สร้างอัตโนมัติ อย่าแก้ด้วยมือ** |
| `act1.html`, `act2.html` | เนื้อหาแต่ละ Act แยกตามพื้นที่ + เช็คลิสต์ |
| `assets/areas.js` | ลำดับพื้นที่ทั้งเกม ใช้ตัดสิน gate |
| `assets/gate.js` | ตัวตั้งความคืบหน้า · ซ่อนบล็อกเกิน gate · ป้ายสปอยล์ · เช็คลิสต์ (localStorage) |

## เขียนเนื้อหา
- บล็อกพื้นที่: `<section class="gated" data-act="1" data-area="<id ใน areas.js>"><h2 class="gtitle"></h2><div class="gbody">…</div></section>` — ไม่ใส่ชื่อพื้นที่ใน `h2` (JS เติมให้เมื่ออยู่ในความคืบหน้า)
- gate ระดับ Act (เช่น ภาพรวม Act): ไม่ใส่ `data-area` แต่ใส่ `data-title="<หัวข้อ>"` — JS ใช้เป็นหัวข้อเมื่อผ่าน gate (ไม่ใส่ = หัวข้อว่าง) · พื้นที่ที่ไม่อยู่ใน `areas.js` ถือว่าเกินเสมอ
- **ห้ามเปลี่ยน/ลบ `id` ใน `areas.js`** ที่ใช้แล้ว (ความคืบหน้าของผู้อ่านเก็บเป็น id · id ที่หายจะถอยกลับไปพื้นที่แรกของ Act) · เพิ่มพื้นที่ใหม่ได้ด้วยการแทรก
- Act ที่เล่นได้หลายลำดับ: เรียงตามเส้นทางที่ผู้เล่นส่วนใหญ่ไป (เช่น ตามเลเวลแนะนำ) · ผู้อ่านที่ไปนอกลำดับใช้ปุ่ม "เปิดดูบล็อกนี้" ทีละบล็อกแทนการเลื่อนความคืบหน้าข้ามพื้นที่ที่ยังไม่ไป
- ในหน้า `act*.html` ทุกเนื้อหาใน `<main>` ต้องอยู่ใน `<section data-act>` (ยกเว้น `h1`, `p.meta`, `noscript`) · ใส่ลำดับพื้นที่ของ Act ใน `areas.js` ก่อนเขียนเนื้อหา Act นั้น
- ผู้อ่านเลื่อนความคืบหน้าไปข้างหน้าต้องกดยืนยันทุกครั้ง (กันกดพลาด)
- เรื่องราว/จุดหักมุม: ห่อด้วย `<div class="spoiler">…</div>` (ซ่อนเสมอ · JS ย้ายเนื้อหาเข้า `.sbody` แล้วซ่อนจนกว่าจะกด · ไม่มี JS = ไม่แสดงกล่องเลย)
- เช็คลิสต์: `<ul class="checklist" data-id="<หน้า-พื้นที่>"><li data-key="<คีย์คงที่>">…</li></ul>` — อย่าเปลี่ยน `data-key` เดิม ไม่งั้นติ๊กของผู้อ่านหาย
- ทุกบล็อกต้องมีแหล่งที่มา (URL) + ป้ายความมั่นใจ `สูง/กลาง/ต่ำ` · เขียนสรุปใหม่เป็นไทย ไม่คัดลอกข้อความ

## ห้ามมีใน repo นี้
ข้อมูลส่วนตัวของผู้เล่น (log, สถานะ, ผลที่เล่าในแชท) ทั้งในไฟล์และใน **ข้อความ commit** (ห้ามมี id/ลิงก์ session) · ทุกหน้ามี `<meta name="robots" content="noindex">`

## ตรวจก่อน push ทุกครั้ง (สคริปต์อยู่ใน repo ต้นทาง)
- `export_site.py check` — path/ข้อความต้องห้ามในไฟล์และข้อความ commit · เนื้อหาหน้า Act อยู่ใน gate
- `export_site.py browser` — เปิดทุกหน้าใน Chromium จริง: ค่าเริ่มต้นซ่อนหมด · กล่องสปอยล์ไม่แสดงข้อความก่อนกด · ความคืบหน้าที่ id ไม่รู้จักไม่เปิดเนื้อหา · ไม่มี JS ซ่อนหมด · เช็คลิสต์อยู่หลังรีโหลด
