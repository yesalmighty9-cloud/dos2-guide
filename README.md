# คู่มือ DOS2 (dos2-guide)

คู่มือเล่น Divinity: Original Sin 2 – Definitive Edition ภาษาไทย แบบกันสปอยล์ · static HTML ล้วน เปิดผ่าน GitHub Pages

## โครงสร้าง
| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | หน้าแรก + วิธีใช้ (ต้นแบบ header/footer ของทุกหน้า) |
| `mechanics.html` | ระบบเกม & บิลด์ — **ไฟล์สร้างอัตโนมัติ อย่าแก้ด้วยมือ** |
| `act1.html` | เนื้อหา Act 1 แยกตามพื้นที่ + เช็คลิสต์ |
| `assets/areas.js` | ลำดับพื้นที่ทั้งเกม ใช้ตัดสิน gate |
| `assets/gate.js` | ตัวตั้งความคืบหน้า · ซ่อนบล็อกเกิน gate · ป้ายสปอยล์ · เช็คลิสต์ (localStorage) |

## เขียนเนื้อหา
- บล็อกพื้นที่: `<section class="gated" data-act="1" data-area="<id ใน areas.js>"><h2 class="gtitle"></h2><div class="gbody">…</div></section>` — ไม่ใส่ชื่อพื้นที่ใน `h2` (JS เติมให้เมื่ออยู่ในความคืบหน้า)
- gate ระดับ Act: ไม่ใส่ `data-area` · พื้นที่ที่ไม่อยู่ใน `areas.js` ถือว่าเกินเสมอ
- เรื่องราว/จุดหักมุม: ห่อด้วย `<div class="spoiler">…</div>` (ซ่อนเสมอ)
- เช็คลิสต์: `<ul class="checklist" data-id="<หน้า-พื้นที่>"><li data-key="<คีย์คงที่>">…</li></ul>` — อย่าเปลี่ยน `data-key` เดิม ไม่งั้นติ๊กของผู้อ่านหาย
- ทุกบล็อกต้องมีแหล่งที่มา (URL) + ป้ายความมั่นใจ `สูง/กลาง/ต่ำ` · เขียนสรุปใหม่เป็นไทย ไม่คัดลอกข้อความ

## ห้ามมีใน repo นี้
ข้อมูลส่วนตัวของผู้เล่น (log, สถานะ, ผลที่เล่าในแชท) · ตรวจด้วยสคริปต์ `export_site.py check` จาก repo ต้นทาง
