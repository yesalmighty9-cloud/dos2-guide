ทิปผู้เล่นใหม่ (ระบบทั่วไป — ไม่มีเนื้อเรื่อง)

สรุปสั้น

  • เซฟ: quicksave F5 / quickload F8 · ใช้หลายช่องเซฟ (autosave ทับกันเอง) กลาง
  • Alt ค้าง = ไฮไลต์ของที่หยิบได้ · คลิกขวาที่ของ/คน = เมนูตัวเลือก กลาง
  • Wits ช่วยหากับดักและของซ่อน + เพิ่ม Initiative (ลำดับเทิร์น) กลาง
  • Loremaster + Identifying Glass ใช้ระบุไอเทม (ของยังไม่ระบุ = ค่าบางอย่างซ่อนอยู่) และดูข้อมูลศัตรู (ต้านทานอะไร) กลาง
  • Pet Pal (talent) คุยกับสัตว์ได้ → ได้ข้อมูล/เควสเพิ่ม · แหล่งไกด์ส่วนใหญ่แนะนำให้มีเสมอ กลาง
  • Persuasion (ทักษะพลเรือน) + ค่าสถานะที่บทสนทนาทดสอบ (เช่น Strength) → เปิดทางเลี่ยงการต่อสู้/ได้ข้อมูล กลาง
  • อุปกรณ์ตามเลเวลสำคัญมาก: เกราะ/อาวุธเลเวลต่ำกว่าเราหลายเลเวล = อ่อนลงชัดเจน → เปลี่ยนของบ่อย กลาง
  • Opportunity attack เกิดเฉพาะตัวที่มี talent Opportunist ต่ำ
  • ในการต่อสู้: ปุ่ม Delay Turn เลื่อนเทิร์นไปท้ายรอบ · Flee หนีการต่อสู้ได้ถ้าอยู่ห่างศัตรูพอ ต่ำ
  • ตายตัวเดียว (เล่นคนเดียว) = จบเกม → ใช้ Resurrection Scroll กับเพื่อนร่วมทีมเท่านั้น ต่ำ

ทริค / cheese

  • ห้ามตีหรือขโมยจาก NPC ที่เป็นกลางถ้าไม่ได้เซฟ — NPC ที่ตายอาจเป็นคนให้เควส
  • เซฟก่อนเปิดบทสนทนาสำคัญ บทสนทนาอาจกลายเป็นการต่อสู้

ข้อควรรู้ความยาก Explorer (DE)

สรุปสั้น

  • ผู้เล่นได้: เลือด +50% · ดาเมจ +50% · เกราะกายภาพ/เวท +30% · โอกาสโจมตีโดน +5% · หลบ +5% กลาง
  • NPC ศัตรูโดน: เลือด −20% · ดาเมจ −30% · เกราะกายภาพ/เวท −30% · โอกาสโจมตีโดน −15% กลาง
  • AI ศัตรูฉลาดน้อยลง ใช้พื้นผิวและคอมโบน้อยกว่า Classic
  • Story mode แรงกว่า Explorer อีกขั้น (เปลี่ยนความยากได้ในเมนูเกมระหว่างเล่น) กลาง

ทริค / cheese

  • ถ้าติดการต่อสู้จริงๆ เปลี่ยนเป็น Story ชั่วคราวได้ แล้วค่อยเปลี่ยนกลับ ต่ำ

เกราะ (Armor) กับการควบคุม (Crowd Control)

สรุปสั้น

  • ทุกตัวมี 3 แถบ: เกราะกายภาพ (Physical Armour) สีเทา · เกราะเวท (Magic Armour) สีฟ้า · เลือด (Vitality) สีแดง
  • ดาเมจกายภาพต้องกินเกราะกายภาพให้หมดก่อน จึงเข้าเลือด · ดาเมจธาตุ/เวทกินเกราะเวทก่อน
  • สถานะควบคุม (สตัน, แช่แข็ง, ล้ม, หลับ, กลัว ฯลฯ) ติดไม่ได้ถ้าเกราะประเภทเดียวกันยังเหลือแม้แต่ 1 แต้ม
    • สถานะจากสกิลกายภาพ (เช่น Knocked Down) → ต้องทำลายเกราะกายภาพก่อน
    • สถานะจากสกิลเวท (เช่น Stunned, Frozen) → ต้องทำลายเกราะเวทก่อน
    • สกิลที่ถูกเกราะกันยังทำดาเมจใส่เกราะตามปกติ แค่สถานะไม่ติด
  • ข้อยกเว้นที่รู้กัน: สถานะ Slowed มักติดได้แม้มีเกราะ ต่ำ

ทริค / cheese

  • ศัตรูที่เกราะกายภาพหนามักเกราะเวทต่ำ (และกลับกัน) → เปลี่ยนเป้าไปตีตัวที่ตรงกับดาเมจของเรา

พื้นผิว (Surfaces) และธาตุ

สรุปสั้น

  • สกิล/ระเบิด/ถังทำให้เกิดพื้นผิวบนพื้น (หรือเป็นเมฆในอากาศ) แล้วพื้นผิวทำปฏิกิริยากับธาตุ
  • คอมโบพื้นฐาน:
    • น้ำมัน (Oil) + ไฟ → ไฟลุก · น้ำมันเฉยๆ ทำให้ช้า (Slowed)
    • พิษ (Poison) + ไฟ → ระเบิด/ไฟลุก
    • น้ำ (Water) + สายฟ้า → น้ำช็อต (Electrified) ติดสตัน · น้ำ + น้ำแข็ง → พื้นน้ำแข็งลื่น (ล้ม)
    • เลือด (Blood) แช่แข็งหรือช็อตได้เหมือนน้ำ
    • น้ำ/ฝน ดับไฟได้ · ไฟ + น้ำ → ไอน้ำ (เมฆ) บังการมองเห็น · ไอน้ำ + สายฟ้า → เมฆช็อต
  • Bless เปลี่ยนพื้นผิวให้เป็นผลดี · Curse เปลี่ยนเป็นผลร้ายล้วน (เช่น พิษต้องสาปทำลายเกราะกายภาพ) กลาง
  • ลำดับมีผล: พื้นผิวที่ค้างอยู่ (น้ำ) ถูกธาตุที่มาทีหลัง (สายฟ้า) เปลี่ยนได้ · แต่ถ้าปล่อยสายฟ้าก่อนแล้วค่อยเทน้ำ มักไม่ช็อต กลาง

ทริค / cheese

  • ยิงหรือโยนถังใส่กลุ่มศัตรูก่อนเริ่มการต่อสู้ แล้วจุดไฟ = เปิดฉากได้เปรียบ
  • เก็บ/ย้ายถังที่อันตรายออกจากทางเดินของทีมก่อนสู้ (ดู cheese พื้นฐาน (S3 — ไม่นับเป็นสปอยล์))

Source Points (แต้ม Source)

สรุปสั้น

  • Source Points = ทรัพยากรพิเศษที่ใช้กับ สกิล Source (สกิลแรงมาก) ใช้ 1 ครั้งเสีย Source Point ตามที่สกิลกำหนด
  • เก็บได้สูงสุด 3 แต้ม · ช่องเก็บแต้มปลดล็อกตามเนื้อเรื่อง (ไม่ระบุว่าที่ไหน/เมื่อไร — S1)
  • Source Point ไม่ฟื้นเองเมื่อพัก ต้องเติม ช่องทางเชิงกลไกที่รู้กัน:
    • ยืนบนพื้นผิว Source (ต้องมีช่องว่าง) → ดูดเป็นแต้ม
    • สกิล Source Vampirism ดูดจากเป้าหมายที่มี Source
    • ดูดวิญญาณจาก Soul Jar
    • น้ำพุ Source (เติมซ้ำได้) — มีเฉพาะบางจุดในเกม

ทริค / cheese

  • ถ้ามีจุดเติมที่ใช้ซ้ำได้ ให้ใช้แต้มให้หมดก่อนแวะเติม

การขโมย (Thievery) และการย่อง (Sneaking)

สรุปสั้น

  • ล้วงกระเป๋า: ต้องมี Thievery ≥ 1 → เข้าโหมดย่อง → คลิกที่ NPC
    • มี เพดานน้ำหนัก/เงิน ที่ขโมยได้ต่อครั้ง (มีตัวบอกในหน้าต่าง) เกินเพดาน = ถูกจับ · เพดานเพิ่มตามแต้ม Thievery
  • ของมีเจ้าของ: ไอคอนมือสีแดง = หยิบแล้วนับเป็นการขโมย
  • กรวยสายตา (sight cone) ของ NPC: ทำผิดในกรวย = ถูกเห็น · ย่องแล้วไม่เข้ากรวย = ไม่ถูกเห็น
  • ถูกจับ: NPC จะตามหา ถ้าออกห่างพอเขาจะเลิกตามหา · ถ้าโดนจับได้ ความสัมพันธ์ (attitude) ลดลง อาจถูกเรียกเงิน หรือเกิดการต่อสู้ที่ดึงคนรอบข้างเข้ามาด้วย
  • ย่องในการต่อสู้: ใช้ 4 AP (Guerrilla ลดเหลือ 3 AP ใน DE) ยกเลิกฟรี · ขณะย่องเดินช้าลง 30% กลาง
  • Chameleon Cloak: ทำให้ล่องหน (Invisible) 2 เทิร์นใน DE กลาง

ทริค / cheese

  • ตรึงด้วยบทสนทนา: ให้ตัวละครหนึ่งคุยกับ NPC ไว้ ระหว่างนั้น NPC และกรวยสายตาของเขาจะไม่ขยับ แล้วสลับไปใช้อีกตัวย่องขโมย (ถ้าเล่นตัวเดียวทำไม่ได้)
  • เซฟก่อนขโมยทุกครั้ง

cheese พื้นฐาน (S3 — ไม่นับเป็นสปอยล์)

สรุปสั้น

  • Bedroll (ถุงนอน): กดใช้แล้วฮีลทั้งทีมเต็ม ใช้ซ้ำได้ นอกการต่อสู้ → ไม่ต้องเปลืองยา
  • ถัง: ย้าย/ทำลายถังน้ำมันหรือถังระเบิดที่อยู่ใกล้ทีมก่อนสู้ · ย้ายถังไปวางใกล้ศัตรูแล้วจุดตอนเปิดฉาก
  • หัวลูกศร: จุ่มลูกศร/หัวลูกศรกับถังธาตุ (ไฟ น้ำมัน พิษ) เพื่อทำลูกศรธาตุ กลาง
  • Teleportation (สกิล): ย้ายศัตรูไปจุดที่เสียเปรียบ (ตกที่สูง ลงพื้นผิวอันตราย) หรือย้ายของ
  • Telekinesis (ทักษะ): ยกของหนักจากระยะไกล โยนใส่ศัตรูหรือย้ายถัง
  • เปิดฉากก่อน: ย่องเข้าใกล้ จัดตำแหน่งทีม แล้วเริ่มการต่อสู้ด้วยการโจมตีแรงที่สุด

ทริค / cheese

  • เซฟด่วน (quicksave) ก่อนทุกการต่อสู้และทุกบทสนทนาสำคัญ
  • คำถาม cheese เฉพาะฉาก → เขียนลงเช็คลิสต์ของฉากนั้น ไม่ใช่ไฟล์นี้ (S5)
